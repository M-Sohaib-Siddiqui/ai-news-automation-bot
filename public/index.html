Integration Setup Documentation

Slack Bot Integration Instructions

  1. Go to api.slack.com/apps and click Create New App (From scratch).
  2. Name your app TWF News Bot and select your Slack workspace.
  3. Under OAuth & Permissions, add Bot Token Scopes: chat:write, channels:read, incoming-webhook.
  4. Click Install to Workspace and copy the Bot User OAuth Token (starts with xoxb-...).
  5. Add token to your .env file as SLACK_BOT_TOKEN=xoxb-....
  6. In Slack, right click your desired channel -> View Details -> copy Channel ID (e.g. C081234567).
  7. Invite bot to channel by typing /invite @TWF News Bot inside your Slack channel.

Google Sheets API Integration Instructions

  1. Go to Google Cloud Console and create a project.
  2. Enable Google Sheets API and Google Drive API in API Library.
  3. Go to Service Accounts -> Create Service Account -> Keys -> Add Key -> Create JSON key.
  4. Save key as service_account.json in project directory, or copy raw JSON into GOOGLE_SHEETS_CREDENTIALS_JSON env variable.
  5. Create a Google Sheet and copy its Spreadsheet ID from URL: https://docs.google.com/spreadsheets/d/YOUR_SPREADSHEET_ID/edit
  6. Click Share on your Google Sheet and invite the Service Account email address (found in JSON as client_email) as Editor.

Vercel Deployment & Automation Instructions

  1. Commit codebase to GitHub: git init && git add . && git commit -m "TWF News Bot".
  2. Import project on Vercel Dashboard.
  3. Under Project Settings -> Environment Variables, add all keys from .env.example (e.g. GROQ_API_KEY, SLACK_BOT_TOKEN, GOOGLE_SHEETS_CREDENTIALS_JSON, etc.).
  4. Deploy! Vercel will automatically configure the Python Serverless function and execute the 6-hour Cron job via vercel.json.
